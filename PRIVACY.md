# Privacy Policy — Gamefa Video.js Player

Last updated: October 2026

Gamefa Video.js Player ("the extension") does not collect, store, or transmit any user data.

The extension runs a content script on `https://gamefa.com/groups/*` pages. That script reads the page's DOM to locate `<video>` and `<audio>` elements and replaces them with Video.js 10 custom elements. No information leaves the browser.

The extension makes no network requests, uses no cookies, no local storage, no analytics, and no remote code.

If you have questions, open an issue at https://github.com/loserbadbakht-wq/congenial-fiesta/issues.
